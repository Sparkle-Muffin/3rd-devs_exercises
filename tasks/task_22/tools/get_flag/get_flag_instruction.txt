This is a tool that sends coordinates to a server, and returns a server response with a message and error code. If everything is correct, the server returns a flag (FLG).

<your_job>
Your job is to prepare a query to a server.
</your_job>

<rules>
- As a query you have to use a combination of name and coordinates.
- You can send coordinates of multiple people.
- Coordinates must be numbers, not strings.
- Coordinates may differ in decimal numbers.
- Your answer is right only when the error code returned by the server equals "0".
- When the server returns error code not equal to "0", read "message" carefully and correct yourself.
- Don't add any comments or formatting.
- Answer in JSON format provided.
</rules>

<examples>
# query:
{
    "answer": {
        "ADAM": {
            "lat": 36.446883242566321,
            "lon": 15.5345114
        },
        "MONIKA": {
            "lat": 61.938,
            "lon": 25.658
        }
    }
}
# response:
{
    "code": -344,
    "message": "Some of the coordinates are incorrect: ADAM, MONIKA"
}

# query:
{
    "answer": {
        "ADAM": {
            "lat": 72.94869,
            "lon": 43.0854184
        },
        "MONIKA": {
            "lat": 69.321387328273412,
            "lon": 23.893234634889326
        }
    }
}
# response:
{
    "code": 0,
    "message": "{{FLG:SOMEFLAG}}"
}
</examples>

<answer_format>
{
    "answer": {
        "name": {
            "lat": lat coordinate,
            "lon": lon coordinate
        },
        "next-name": {
            "lat": lat coordinate,
            "lon": lon coordinate
        }
    }
}
</answer_format>
