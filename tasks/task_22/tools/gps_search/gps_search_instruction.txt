This is a tool that returns latitude and longitude for a given ID of a person.

<your_job>
Your job is to prepare a single query to a database.
</your_job>

<rules>
- As a query you have to use a single ID of a person (userID).
- Don't add any comments or formatting.
- Answer in JSON format provided.
</rules>

<examples>

# response:
"message": {

    "lon": 15.534511435678436
}

# query:
"userID": 46
# response:
"message": {
    "lat": 61.938877632198231,
